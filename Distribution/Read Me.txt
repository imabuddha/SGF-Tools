SGF Tools 2.0.8

Board thumbnails and previews of SGF (Go game) files in Finder and Quick Look, Spotlight
search on players, events, dates, and results, and a screensaver that replays games.

Requires a Mac with Apple silicon and macOS 26 or later.


INSTALLING THE APP

1. Drag SGF Tools to the Applications folder.

2. Open SGF Tools once. It's signed with a Developer ID and notarized by Apple, so macOS
   opens it without a warning; the first time, it asks whether you want to open an app
   downloaded from the internet: click Open. (If macOS still won't open it, go to System
   Settings > Privacy & Security, scroll down to Security, and click Open Anyway beside
   the message about SGF Tools.) Then run this in Terminal to reset Quick Look:

       qlmanage -r

3. In Finder, SGF files now show board thumbnails; select one and press the Space bar
   for the preview. If they don't, check that SGF Tools is on in System Settings >
   General > Login Items & Extensions, under Quick Look.

4. Spotlight indexes new and changed SGF files a minute or so later. To index the games
   you already have, run "mdimport -i" on each folder that holds them, for example:

       mdimport -i ~/Documents/Go


INSTALLING THE SCREENSAVER

1. Open SGF Tools and click Update Screensaver Games. macOS asks whether SGF Tools may
   read your Documents folder and your other disks; allow each. The window then says
   how many games it chose.

2. Drag SGF Tools.saver to your Desktop, and double-click it (if macOS asks whether to
   open it, confirm). Choose to install it for this user only. You can then delete the
   copy on the Desktop.

3. In System Settings > Wallpaper, choose Screen Saver, and pick SGF Tools (under
   Other). With more than one display, select each display and choose SGF Tools for
   each.

To update the screensaver later, first run "killall legacyScreenSaver" in Terminal, then
install the new copy as in step 2.
